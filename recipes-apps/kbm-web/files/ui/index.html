Profiles

Each profile is a complete snapshot of tuning, bindings, and burst settings. Switching activates the profile and the daemon hot-reloads instantly. Slider/binding edits persist into the active profile automatically.

Mode-toggle hotkey

Chord that triggers a switch between emulation and passthrough when held for one second. The keys are detected on the BBB-attached keyboard, so you can flip out of emulation mode without needing the webapp focused.

Mode

Emulation: the BBB presents as a DualSense gamepad; the plugged-in keyboard and mouse are translated to controller input. Passthrough: the BBB presents as a USB keyboard + mouse; the plugged-in keyboard and mouse appear natively on the host.

Burst-on-hold

Oscillate a button or trigger while its source input is held. Useful for recoil-control: bind fire (r2) to a burst so click-and-hold pulses the trigger instead of holding it. hz=0 disables; duty is the fraction of each cycle the action is reported pressed (0..1, default 0.5).

Key / mouse mapping

Actions are named in DualSense terms (cross / circle / l2 / r2 / …). Because the Windows bridge translates this gadget to a virtual Xbox 360 controller, in-game prompts (Warzone etc.) show the Xbox equivalents — those are listed in parentheses next to each action name (e.g. cross (A), r2 (RT)).
